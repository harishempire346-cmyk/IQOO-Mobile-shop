# iQOO Mobile Shop

## Project Description
This project is a responsive iQOO Mobile Shop website designed to showcase iQOO smartphones and their features in a simple and user-friendly interface.

## Features
- Attractive home page
- iQOO mobile products display
- Product details
- Responsive design
- Easy navigation
- Contact section

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Project Structure
- index.html
- style.css
- script.js
- images/

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the iQOO Mobile Shop website.
